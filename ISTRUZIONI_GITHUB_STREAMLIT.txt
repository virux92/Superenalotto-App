SUPERENALOTTO — PACCHETTO STREAMLIT CON 1.168 ESTRAZIONI

FILE DA CARICARE NELLA RADICE DEL REPOSITORY GITHUB
- app.py
- estrazioni.csv
- requirements.txt

DEPLOY
1. Apri il repository GitHub già collegato a Streamlit Community Cloud.
2. Sostituisci app.py e requirements.txt.
3. Carica estrazioni.csv nella stessa cartella.
4. Esegui il commit.
5. In Streamlit Community Cloud usa app.py come Main file path.
6. Se l'app è già distribuita, il nuovo commit attiva normalmente il redeploy.

AGGIORNAMENTO DELLO STORICO
- Inserisci la nuova estrazione dalla barra laterale.
- Scarica il nuovo estrazioni.csv.
- Sostituisci il file nel repository GitHub e fai commit.
- Le modifiche fatte soltanto nella sessione Streamlit non sono permanenti.

ARCHIVIO
- 1.168 estrazioni dal 02/01/2020 al 24/07/2026.
- I concorsi 2020-2025 sono completi di Jolly e SuperStar.
- Nei concorsi 2026 dal n. 69 al n. 117 il Jolly non era presente nei dati
  inizialmente forniti; le celle sono lasciate vuote senza inventare valori.

BACKTEST
- Usa finestre mobili da 50, 100 o 200 estrazioni.
- Confronta l'algoritmo con due baseline: soli frequenti e soli ritardatari.
- Per ogni concorso usa soltanto dati precedenti, senza contaminazione futura.
- I risultati non dimostrano prevedibilità: servono a confrontare metodi storici.

NOTA
L'app è un analizzatore e generatore di combinazioni. Ogni specifica sestina
resta equiprobabile rispetto alle altre in un'estrazione regolare.
