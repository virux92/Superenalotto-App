# SuperEnalotto App v2.0

## Aggiornamento

Sostituire nel repository tutti i file con quelli contenuti in questo pacchetto, mantenendo i Secrets Streamlit già configurati.

Dopo il deploy, la schermata principale deve mostrare:

`Fonte dati attiva: Supabase`

Se Supabase non è disponibile, l'app usa automaticamente `estrazioni.csv` e mostra il dettaglio dell'errore.
