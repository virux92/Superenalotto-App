# Versione 2.5.1 — Correzione selezione SuperStar

Correzione mirata del modulo **Schedine monitorate**.

- Il controllo **SuperStar giocato** è ora esterno al form Streamlit.
- Selezionandolo, il campo **Numero SuperStar** si abilita immediatamente.
- Se il controllo non è selezionato, la schedina viene salvata senza SuperStar.
- Nessuna modifica alle estrazioni, alle schedine già registrate o allo schema del database.
