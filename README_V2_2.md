# v2.2 — Statistiche avanzate e validazione

## Novità

- Nuovo modulo `core/analytics.py`.
- Analisi di somme, pari/dispari, decine, consecutivi, ampiezza ed entropia.
- Ranking di coppie e terzine con confronto descrittivo rispetto all'atteso casuale.
- Analisi delle ripetizioni fra estrazioni consecutive.
- Stabilità annuale dei 90 numeri.
- Benchmark casuale deterministico nel backtest.
- Deviazione standard, intervallo di confidenza e risultati annuali del backtest.
- Hash SHA-256 riproducibile dell'archivio.
- Confronto integrità Supabase/CSV nella pagina amministrativa.
- Prima suite di test automatici.
